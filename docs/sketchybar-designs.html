Five directions for your menu bar

Each option gives the same bar on your notched MacBook a different shape. They share one rule: an item earns a spot only if you can act on it, and everything else stays hidden until a threshold trips. Use the controls to see every bar at rest or in the worst case, and on a dark or bright wallpaper.

Status, Nov 2026: all five are built as switchable themes. Quiet Text is the default. Switch with sbtheme <name>. The meeting countdown was dropped, so nothing reads your calendar.

Shared by every option

Rules for staying calm

Hidden until it mattersBattery appears below 20% and unplugged. WARP appears only when it disconnects. MR and on-call items appear only when they're non-zero. Volume appears for 2 seconds after you change it, then hides.
One meeting thresholdThe next meeting turns warm at 5 minutes everywhere. Clicking it opens the video link.
Teammate clock dims off-hoursIST is bright from 09:00 to 19:00 and dim otherwise, so you can tell at a glance whether a ping will be seen. All mockups use 08:40 local, which is 22:10 IST, so it's dim.
Width budget per sideAbout 420px on each side of the notch. When alerts overflow, the three most urgent show and the rest collapse into +N, in this order:
  1. meeting ≤ 5 min
  2. battery < 20%
  3. WARP off
  4. on call
  5. MRs to review
  6. CPU hog

  • Uses the notch on purpose. SketchyBar's q and e positions sit directly left and right of the notch. Black ears there look like part of the hardware, much like Dynamic Island on an iPhone.
  • The left ear is about time. It shows the next meeting, and from 5 minutes out it grows a peach Join button.

# and that JSON error object would count as "1". Pin host + group.

        --reviewer=@me -F json 2>/dev/null) || exit 0

  • Glyphs instead of words. Workspaces are dots, and the focused one stretches into a mauve dash. The app is its icon. At rest the right capsule holds just two muted glyphs and the time.
  • Hover reveals. Pointing at a glyph slides out its label using mouse.entered and --animate. The specimen shows the IST tooltip.
  • Color plus a number means act. A glyph turns peach or red and gains a short count (4m, 18, 2). Every alert stays one glyph wide, so this option has the most room for alerts.
  • The cost is recall: you have to learn what each glyph means. It suits someone who wants the bar to be close to invisible.

Recommendation

B on the laptop, with a fallback for the external monitor

Notch Island gives the MacBook a distinct look and puts the two most time-sensitive signals, the next meeting and the live mic, at the top center of your screen. It already follows the calm rules: battery and WARP stay hidden until they trip. Your external monitors have no notch, so the ears become one centered island. Your AeroSpace config already reserves the 32px gap on those displays.

Fixes in the current config

Bug · verified

The workspace fallback always fails

plugins/current_space.sh:4

aerospace list-workspaces --monitor focused --focused exits with "Conflicting options" on your machine, so the pill stays blank until AeroSpace sends its first event. Use aerospace list-workspaces --focused.

Bug

The startup trigger fires the wrong event

sketchybarrc-laptop: last line

The last line fires space_change, which nothing listens to. Use --trigger aerospace_workspace_change FOCUSED_WORKSPACE=$(aerospace list-workspaces --focused).

Bug

A stray blank line breaks a command

sketchybarrc-laptop:95–97

The \ on line 95 is followed by a blank line, so zsh runs label.drawing=yes as a command and fails with "command not found". You can't see it only because labels draw by default.

Accuracy

Weather reports WARP's exit location

plugins/weather.sh

ipinfo and wttr.in geolocate by IP, so behind WARP they report the exit location, such as San Jose. Hard-code your city, and drop both ipinfo calls.

Cost

The clock runs its script every second

clock · update_freq=1

That's 86,400 script runs a day. Drop the seconds and set update_freq=30.

Accuracy

Memory overstates usage

plugins/memory.sh

It counts inactive pages and ignores compressed memory. Active + wired + compressed comes close to Activity Monitor, or show memory only when memory_pressure reports pressure.

Tidy

Leftovers

rc + plugins

Several small leftovers:

  • label.color is set twice; white wins.
  • The cpu item sets script= twice.
  • weather.moon subscribes to clicks but has no script.
  • memory.sh has no shebang.
  • Both clocks use the same icon.
  • weather.sh's return works under zsh, but exit is clearer.
Heads-up

Hidden items stop polling

SketchyBar 2.24

The default updates=when_shown means an item with drawing=off never runs its script, so it can never turn itself back on. Set updates=on on every exception item.

Process

How this was made

Two review rounds

  • Design review. It found that option E duplicated A's shape, so E is now the Glyph Rail. Four bars ran under the notch; there's now a width budget and an overflow order. Battery, volume, and weather were showing at rest; they're hidden now. The recommendation had no drawing; there's now an external-monitor specimen. The reviewer also asked for this contact sheet and the bright-wallpaper test.
  • Technical review. I checked the snippets against the SketchyBar docs and ran them on your machine. Fixes:
    • The click_script now uses single quotes, so it's evaluated at click time.
    • glab now pins the host and group, so an error doesn't read as "1".
    • The warp-cli grep is exact.
    • The CPU script keeps multi-word process names.
    • updates=on is added to hidden items.
    • The aerospace fallback bug was found and confirmed.
